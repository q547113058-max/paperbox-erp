# Excel 式直编辑改造方案

> **目标：** 去掉 Modal 弹窗，表格即表单 —— 点击格子直接编辑，底部加一行直接新增。
> **范围：** 订单、采购单、送货单三个核心页面。

## 改造模式

```
改前（弹窗模式）：
  表格行 → 点「编辑」→ 弹窗出现 → 填表单 → 点保存 → 弹窗关闭
  点「新建」→ 弹窗出现 → 填表单 → 点保存 → 弹窗关闭

改后（Excel 模式）：
  表格行 → 点「编辑」→ 该行变输入框 → 改值 → 点「保存」✓ → 行恢复显示
  底部「+ 新增一行」→ 空行出现（含输入框）→ 填值 → 点「保存」✓
```

## 技术方案

使用 Ant Design 的 editable row 模式：
- `EditableCell` 组件：根据 editing 状态切换 显示/编辑 模式
- `EditableRow` 组件：封装行编辑上下文
- 共享组件放 `apps/web/src/components/EditableTable.tsx`
