# 销售订单页面重构计划

> **目标:** 将销售订单改为直接进入新增页面（含下方列表），按用户指定的列定义重新设计明细表格

**架构:** Orders.tsx 全页新建表单（非弹窗） + 下方嵌入订单列表，共享同一页面

**技术栈:** React + Ant Design + TypeScript，后端不变

---

## 用户需求

1. 点击"销售订单"→ 直接进入新增页面
2. 自动生成销售单号
3. 手工输入客户名称（保留搜索下拉）、客户订单号
4. 下方 Excel 式多行表格，列序：客户编码、物料编码、物料名称、物料规格、单位、数量、单价、总价、下单日期、交期、备注
5. 输入物料信息时自动弹出已录入物料供选择
6. 确认保存弹窗
7. 保存后在下方列表中能查询到

## 实施任务

### Task 1: 重写 Orders.tsx — 头部表单区

- 显示自动生成的订单号（占位，保存后由后端生成）
- 客户名称：搜索下拉 `<Select showSearch>`（保留 customer_id）
- 客户订单号：`<Input>` 手工输入
- 下单日期：`<DatePicker>` 默认当天
- 交期：`<DatePicker>`
- 备注：`<Input>`

### Task 2: 重写 Orders.tsx — 明细表格

修改 `itemColumns` 为新列序：
- 客户编码（从产品 customer_code 读取）
- 物料编码（从产品 code 读取）
- 物料名称（从产品 name 读取）
- 物料规格（从产品 spec 读取）
- 单位（从产品 unit 读取）
- 数量（InputNumber 可编辑）
- 单价（InputNumber 可编辑）
- 总价（自动 = 数量×单价）
- 下单日期（DatePicker 可编辑）
- 交期（Input 可编辑）
- 备注（Input 可编辑）
- 操作（删除按钮）

### Task 3: 物料自动补全搜索栏

保留现有"搜索选择物料 → 填入数量/单价 → 添加"工具栏模式，增强显示格式

### Task 4: 确认保存弹窗

- 保存前弹出 Modal 显示订单摘要
- 显示：客户名称、总金额、明细行数
- 确认 / 取消

### Task 5: 下方嵌入订单列表

在表单下方显示已有订单列表（简化版，复刻当前 Orders.tsx 的列表部分）
