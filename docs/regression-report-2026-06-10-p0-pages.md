## 4. P0/P1/P2 问题清单

### P1

#### P1-1 销售订单：右侧金额/操作列视觉拥挤，疑似 fixed 操作列遮挡感

现象：`/orders` 表格操作按钮较多，部分行右侧金额列与操作列之间存在视觉挤压；browser_vision 判断可能有 fixed 操作列遮挡感。

风险：影响销售订单金额阅读和操作扫描效率。

建议：
- 增大 `scroll.x` 与操作列宽
- 操作列低频动作收纳进「更多」
- 金额列加 `white-space: nowrap`

#### P1-2 采购：采购单号列宽不足，长单号换行断裂

现象：`PO20260609071836779` 等长采购单号被拆行。

风险：核对/复制单号易出错，表格行高不稳定。

建议：单号列加宽，或 `nowrap + ellipsis + Tooltip`。

#### P1-3 采购：操作按钮过多，待审批行拥挤

现象：待审批行同时展示详情/审批/驳回/入库/打印/编辑/删除/取消。

风险：误点危险操作，表格视觉负担大。

建议：保留详情/审批/入库，其他放「更多」。

#### P1-4 发货：表格出现 `ID:null`

现象：`/deliveries` 中多行客户或关联订单展示为 `ID:null`。

风险：直接暴露技术型兜底文案，影响业务可信度；可能表示旧数据关联缺失或前端 null 兜底不当。

建议：
- 前端不要显示 `ID:null`，改为 `未关联` / `未知客户` / `-`
- 后端/数据排查 delivery 的 `order_id/customer_id` 关联

#### P1-5 应收：到期日列宽不足，部分日期疑似截断

现象：红色逾期日期显示类似 `2026-04-2`、`2026-05-0`。

风险：应收账期判断依赖完整到期日，截断会影响催收优先级判断。

建议：到期日列加宽并 `nowrap`。

#### P1-6 应收：操作按钮拥挤

现象：详情/结清/冲正/编辑/删除同时展示，部分行换行。

风险：误点冲正/删除等危险操作。

建议：危险/低频操作收纳到「更多」。
