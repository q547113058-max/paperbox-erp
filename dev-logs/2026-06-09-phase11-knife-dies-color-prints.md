## 功能详情

### KnifeDies.tsx（刀模管理）

**表格列**：
- 刀模号、客户、制品名称、产品规格(cm)、模板尺寸(mm)、模切、盒型、刀模费、图片、操作

**表单字段**：
- 刀模号（必填）、盒型（下拉）、客户（下拉）、刀模费、制品名称、产品规格(cm)、模板尺寸(mm)、模切（下拉）、刀模图片

**功能**：
- 新建/编辑/删除
- 搜索（刀模号/客户/制品名称）
- 图片上传（ImageUpload 组件）
- 盒型/模切选项从 spec-options API 加载

### ColorPrints.tsx（彩印管理）

**统计卡片**：
- 总彩印数、正常数、总印件数、总图片数

**表格列**：
- 彩印编号（可点击查看详情）、名称、关联产品、客户、印件数、图片数、状态、创建时间、操作

**表单字段**：
- 名称（必填）、关联产品（下拉）、客户（下拉）、备注
- 印件列表（Form.List）：印件名称、尺寸结构、材料、机器尺寸

**功能**：
- 新建/编辑/删除
- 详情弹窗（Descriptions + 印件列表 + 图片预览）
- 搜索（单号/名称）
- 状态管理（正常/停用）
