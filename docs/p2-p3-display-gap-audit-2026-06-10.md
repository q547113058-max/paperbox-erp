## 建议排序

1. P2 Products：图片/印件/刀模/客户产品编码/字典项展示差异最大，但不阻断当前下单-采购-发货链路。
2. P2 Dashboard：旧系统库存率、低库存、签收流水等运营指标仍未完整复刻；适合作为管理驾驶舱增强。
3. P2 WarehouseEntry / WorkshopInventory：进仓与车间库存旧页面仍有扫码/部分发货/库存流水展示差异。
4. P2 Settings / ActionLogs / GlobalSearch：权限设置、操作日志、全局搜索属于审计/管理增强；业务上线前可继续补。
5. P3 Guide / ImageLibrary：文档和图库入口，优先级低于核心业务页。
