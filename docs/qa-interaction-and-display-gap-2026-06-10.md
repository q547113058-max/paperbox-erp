### 范围

测试服 `http://193.112.246.85:3003/`，覆盖 5 个核心业务页：

- 发货管理 `/deliveries`
- 采购管理 `/purchases`
- 订单管理 `/orders`
- 应收管理 `/receivables`

### 方法

使用 browser_console 注入 JS，自动遍历页面上的按钮：
- 安全操作（详情/新建/编辑/打印/更多菜单）→ 点击后验证弹窗/菜单是否正确打开
- 危险操作（审批/入库/发货/签收/结清）→ 跳过不点，或仅打开确认弹窗后取消
- 操作完成后自动关闭所有弹窗，确保无侧效应

## 二、P2/P3 展示差异（C）

### 方法

- 静态代码扫描：提取旧 `/data/erp-data/erp-system/client/src/pages/*.jsx` vs 新 `/root/workspace/paperbox-erp/apps/web/src/pages/*.tsx` 的 columns/buttons/tabs/statuses
- 旧系统 Dashboard browser_vision 截图：确认 6 KPI + 3 表格 + 全局搜索
- headless SPA 路由限制：旧系统除 Dashboard 外其他页面无法在 headless 中导航

### 高价值 P2 候选（推荐优先补）

| 页面 | 差异摘要 | 业务影响 |
|------|----------|----------|
| **Products** | 缺印件/刀模/客户产品编码/字典项 38 个字段 | 中，但不阻断下单-采购-发货链路 |
| **Dashboard** | 缺库存预警（产品/当前库存/安全库存/库存率）、最近送货签收列、本月收入利润 KPI | 中，管理看板增强 |
| **WorkOrders** | 缺完成进度、啤线图/坑纸/面纸尺寸、发数量/已发货/待发数量 | 中，车间管理增强 |
| **OutsourcingOrders** | 缺上机数量/印件信息/印刷成品数/颜色/尺寸/工单号/已收货/进仓等 | 中，委外管理增强 |
| **Purchases** | 缺下单日期/产品名称/客户/规格/物料/从工单生成等 | 低，核心采购流程已通 |
| **Deliveries** | 缺产品名称/单位/序号/金额等明细列 | 低，核心发货流程已通 |
| **Finance** | 缺固定项/月份聚合/收支分类/导出报表等 | 低，应收应付已独立 |
| **Customers** | 缺是否含税/材料类型/结算方式/账期/返点数 | 低，基础资料增强 |
| **ReconciliationBills** | 缺送货单关联明细/结清确认流程 | 低 |
| **Settings** | 整页缺失（账号/权限管理） | 低，单人使用场景暂不影响 |
| **WarehouseEntry** | 整页缺失（扫码/部分发货/关联送货单） | 低，当前暂未用进仓 |
| **WorkshopInventory** | 整页缺失（车间库存管理） | 低，后端 API 已有 |

### P3 候选（低优先级）

| 页面 | 差异摘要 |
|------|----------|
| **ActionLogs** | 整页缺失（操作日志审计） |
| **GlobalSearch** | 整页缺失（跨模块全局搜索） |
| **Guide** | 整页缺失（使用说明） |
| **ImageLibrary** | 整页缺失（图片库管理） |
| **ColorPrints** | 缺印件图片上传/连续新建等 |
| **KnifeDies** | 缺图片上传/添加客户字典 |
| **Payables/Receivables** | 旧版独立页字段差异（但新版统一财务模块已覆盖） |
| **Personnel** | 缺地址/联系人/最后合作时间 |

### 建议排序

1. **P2 Products**：字段差异最大，但不阻断核心链路，适合管理增强时补齐
2. **P2 Dashboard**：旧版库存预警 + 收入利润 KPI 可提升管理效率
3. **P2 WorkOrders / OutsourcingOrders**：生产/委外管理增强
4. **QA-1/2/3 确认弹窗**：Medium 级交互安全问题，应尽快修复
5. **P2 Settings / ActionLogs / GlobalSearch**：审计管理增强
6. **P3 页面**：最后补齐，不影响核心业务
